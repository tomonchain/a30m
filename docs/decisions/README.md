# Decisions

Numbered decisions, continuing Airth v0's (1 to 154, archived in [tomonchain/airth](https://github.com/tomonchain/airth/blob/v0-final/docs/decisions.md)).

- [`decisions.md`](decisions.md): the decisions taken for a30m, newest first, from 155.
- [`legacy.md`](legacy.md): each of v0's decisions, and whether it holds in a30m.

A structural choice (new module, new dependency, new stored state, a change to a boundary) gets an entry at the top of `decisions.md`: what was decided, *Why*, *Cost*. A new decision names the ones it changes. **Proposed** marks one that waits for the founder.
